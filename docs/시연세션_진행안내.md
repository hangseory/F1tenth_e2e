# 시연 세션 진행 안내

신입부원 대상. **맵 만들기 → 경로 그리기 → 자율주행** 한 바퀴를 직접 돌려봅니다.

> 터미널을 **3개** 씁니다. 헷갈리지 않게 미리 이름을 붙여두세요.
>
> | | 어디서 | 무엇 |
> |---|---|---|
> | **젯슨 A** | 노트북에서 SSH | 주행 스택 (mapping / q1 / race) |
> | **젯슨 B** | 노트북에서 SSH | 저장·설정 (savemap / tune) |
> | **노트북** | 노트북 로컬 | RViz 화면 보기 |

---

## 0. 네트워크 — 먼저 확인할 것

젯슨과 노트북을 **둘 다 `yax_5g`** 에 연결합니다.

> ### 스택을 켠 뒤에는 와이파이를 바꾸지 마세요
>
> 통신 계층(CycloneDDS)이 **기동 시점의 IP 로 네트워크 인터페이스를 고정**합니다.
> 그 뒤 와이파이를 바꾸면 노드는 살아 있는데 **서로 못 듣는 상태**가 됩니다.
> 조향이 갑자기 먹통이 되는 식이라 하드웨어 고장처럼 보입니다.
>
> 바꿨다면 반드시 `./race.sh stop` 후 다시 띄우세요.

---

## 1. 젯슨 접속

**노트북 터미널에서:**

```bash
ssh jetson@192.168.50.57          # 비밀번호: jetsonjetson
```

터미널을 2개 열어 각각 접속해 둡니다 (**젯슨 A**, **젯슨 B**).

---

## 2. 맵 만들기

### 2-1. 맵핑 시작 — 젯슨 A

```bash
cd yax
./race.sh mapping-joy
```

**역할** — 라이다·VESC·IMU 를 띄우고 **SLAM(slam_toolbox)** 을 돌립니다.
조이스틱으로 차를 몰면 지나간 곳이 맵으로 그려집니다.

> ### ★ 차를 세운 자리가 곧 출발선입니다
>
> SLAM 은 **맵핑을 시작한 순간의 차 위치**를 맵 원점 `(0, 0, 0°)` 으로 삼습니다.
> 나중에 주행할 때도 **그 자리에 그 방향으로** 세워야 위치추정이 맞습니다.
>
> 그러니 **트랙 위 출발시킬 자리에 차를 놓고** 시작하세요.

### 2-2. 화면 보기 — 노트북 (SSH 아님, 로컬)

```bash
cd yax
./rviz.sh 57
```

**역할** — 젯슨이 만들고 있는 맵·라이다 스캔·차 위치를 실시간으로 봅니다.
인자 `57` 은 1호차 젯슨의 IP 끝자리입니다 (`./rviz.sh car1` 도 같습니다).

이제 **조이스틱으로 트랙을 한 바퀴** 천천히 돌아 맵을 채웁니다.
RViz 에서 벽이 빠짐없이 그려졌는지 확인하세요.

### 2-3. 맵 저장 — 젯슨 B

```bash
cd yax
./race.sh savemap 0920            # 이름은 자유. 날짜를 쓰면 찾기 쉽습니다
```

**역할** — 지금 맵을 `maps/0920.pgm` + `.yaml` 로 저장하고,
**출발점 좌표를 자동으로 기록**합니다 (`init_x/y/yaw = 0,0,0` = 맵 원점 = 맵핑 시작 자리).

저장이 끝나면 **젯슨 A** 의 맵핑을 `Ctrl+C` 로 끕니다.

---

## 3. 경로(웨이포인트) 그리기 — 젯슨 A

```bash
./race.sh line2
```

맵 목록이 뜨면 **방금 저장한 이름을 입력하고 Enter**.

**역할** — 맵 위에 마우스로 경유점을 찍으면, 벽에서 밀어내며 부드럽게 다듬어
차가 따라갈 **레이싱 라인**을 만듭니다.

### 클릭 창 조작

| 키 | 동작 |
|---|---|
| **`c`** | **열린 경로 ↔ 닫힌 루프 토글 — 트랙을 도는 거면 먼저 한 번 누르세요** |
| 좌클릭 | 경유점 추가 |
| 우클릭 / `u` | 직전 점 취소 |
| `d` | 전부 지우기 |
| **Enter** | 확정 → 다듬어서 저장 |
| `q` | 취소 |

트랙 중앙을 따라 **10~20 점** 정도 찍으면 충분합니다. 촘촘히 찍을 필요 없습니다.

저장되면 `waypoints/<맵이름>_free_wp.csv` 가 생깁니다.

---

## 4. 설정에 반영 — VS Code

`race_script.yaml` 을 열어 **58 줄 / 60 줄** 을 방금 만든 이름으로 바꿉니다.

```yaml
58:  map_name: 0920               # 맵 이름 (.yaml 확장자 없이)
60:  waypoints: 0920_free_wp      # 웨이포인트 이름 (.csv 확장자 없이)
```

**역할** — 주행 스택이 "어느 트랙에서, 어느 라인을 따라" 달릴지 정하는 곳입니다.
이 파일이 팀이 만지는 **유일한 설정 파일**입니다.

## 5. 자율주행

### 5-1. 경로 추종 확인 — 젯슨 A

```bash
./race.sh q1
```

**역할** — 장애물 없이 **라인만 따라 도는** 모드입니다. 라인이 제대로 그려졌는지,
차가 잘 따라가는지 먼저 봅니다.

### 5-2. 장애물 회피 확인

트랙에 콘을 몇 개 놓고:

```bash
./race.sh race
```

**역할** — 라인을 따라가되 **앞에 뭔가 있으면 옆으로 비켜** 지나갑니다.

### 5-3. 화면 — 노트북

```bash
./rviz.sh 57
```

RViz 에서 볼 것:

| 색 | 무엇 |
|---|---|
| **노란 정육면체** | 차가 지금 **조준하는 점** (회피 오프셋 반영됨) |
| 초록~빨강 선 | 레이싱 라인 (색 = 구간별 목표 속도) |
| 빨간 점들 | 라이다 스캔 |
| 화살표 | 위치추정이 말하는 차의 자세 |

---

## 6. 위치추정이 맞는지 확인

**가장 중요한 확인입니다.** 라이다 스캔(빨간 점)이 **맵의 벽과 겹쳐 보여야** 합니다.
어긋나 있으면 차는 자기가 어디 있는지 모르는 상태입니다.

어긋났다면 RViz 상단의 **`2D Pose Estimate`** 를 누르고,
맵에서 차의 **실제 위치를 클릭한 채 진행 방향으로 드래그**해 놓아줍니다.

> 맞춘 자리를 다음 실행에도 쓰려면 **젯슨 B** 에서:
> ```bash
> ./race.sh savepose
> ```
> 실행 후 `race_script.yaml` 의 `init_x` 값이 **실제로 바뀌었는지 눈으로 확인**하세요.
> 스택이 완전히 뜨기 전에 실행하면 조용히 실패합니다.

## 7. 조이스틱

### 출발

**`A` 버튼** 을 누르면 자율주행이 시작됩니다.
(터미널에 `출발 준비 완료` 배너가 뜬 뒤에 눌러야 합니다. 어느 버튼인지도 배너에 나옵니다.)

스택을 미리 띄워두고 신호에 맞춰 출발하기 위한 구조입니다.
그동안 위치추정이 수렴할 시간도 법니다.

### 수동 ↔ 자율 전환

| 버튼 | 동작 |
|---|---|
| **`L1`** | 수동주행 모드 토글 (누르면 사람이 조작, 다시 누르면 자율) |

### 수동 조작

| 조작 | 동작 |
|---|---|
| **왼쪽 스틱 좌우** | 조향 |
| **`RT`** | 전진 (많이 당길수록 빠름) |
| **`RB` + `RT`** | 후진 |

> 자율주행 중 위험하면 **`L1` 을 눌러 수동으로 뺏어오세요.** 컨트롤러가 즉시 멈춥니다.

## 8. 속도 바꿔보기 — 젯슨 B

```bash
./tune.sh q1=0.8
```

**역할** — `race_script.yaml` 을 직접 열지 않고 값만 안전하게 고칩니다.
`q1` 은 **q1 모드에서 쓸 마찰 예산 비율**입니다 (0~1, 클수록 빠름).

속도는 `v ∝ √η` 로 변합니다 — 0.4 → 0.8 이면 약 1.4 배 빨라집니다.

> 모드마다 키가 다릅니다. `./race.sh q1` 은 `q1` 만, `./race.sh race` 는 `race` 만 씁니다.
> 바꾼 뒤에는 **스택을 다시 띄워야** 적용됩니다.

값 목록과 설명은 `./tune.sh -h` 로 볼 수 있습니다.

---

## 9. 마무리

```bash
./race.sh stop
```

**역할** — 남아 있는 노드를 전부 정리합니다. 다음 사람이 깨끗한 상태에서 시작할 수 있게
**세션이 끝나면 꼭 실행**하세요.

## 잘 안 될 때

| 증상 | 확인 |
|---|---|
| RViz 에 아무것도 안 뜸 | 노트북·젯슨이 **같은 와이파이**인가. `./rviz.sh 57` 의 숫자가 맞는가 |
| 차가 엉뚱한 데 있다고 나옴 | 스캔과 맵이 겹치는가 → `2D Pose Estimate` 로 맞추기 |
| 갑자기 조향이 안 먹음 | 스택 켠 뒤 **와이파이를 바꿨는가** → `./race.sh stop` 후 재시작 |
| 출발 버튼을 눌러도 안 나감 | 터미널에 `출발 준비 완료` 배너가 떴는가 |
| 주행 중 갑자기 멈춤 | 터미널 확인. `위치추정 폭주` 면 위치를 잃은 것 → 재정렬 후 재시작 |
| 토픽이 도는지 모르겠음 | 다른 터미널에서 `./race.sh check` |

## 명령어 한 장 요약

| 명령 | 역할 |
|---|---|
| `./race.sh mapping-joy` | 맵 만들기 (조이스틱으로 몰면서 SLAM) |
| `./race.sh savemap <이름>` | 맵 저장 + 출발점 자동 기록 |
| `./race.sh line2` | 클릭으로 레이싱 라인 그리기 |
| `./race.sh q1` | 라인만 따라 주행 |
| `./race.sh race` | 라인 주행 + 장애물 회피 |
| `./race.sh savepose` | 지금 위치를 출발점으로 저장 |
| `./race.sh check` | 토픽·TF 가 살아 있는지 표로 확인 |
| `./race.sh stop` | 전부 정리 |
| `./tune.sh q1=0.8` | 설정값 안전하게 수정 |
| `./rviz.sh 57` | (노트북) 실시간 화면 |
