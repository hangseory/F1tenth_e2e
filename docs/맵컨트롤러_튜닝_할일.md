## 1. 할 일 체크리스트

순서대로, **한 번에 하나만** 바꾸고 달려서 확인할 것.

### ☐ 1-1. `slip_gain` 0.5 → 0.85 (위험 낮음)

- 파일: `config/vehicle_car1.yaml` → `tuning.slip_gain`
- 근거: 실측 언더스티어 0.012 rad / (㎧²). 컨트롤러 모델(Pacejka, μ 0.63)은
  `slip_gain 1.0` 에서 0.0143, 0.5 에서 0.0071 → 실측에 맞는 값 약 0.85
- 주의: 8월에 1.0 에서 과조향(곡률 1.2~1.9배)이 난 기록이 있어 1.0 이 아니라 0.85
- 확인: 코너 바깥 치우침이 줄었는지, 코너에서 좌우로 흔들리지 않는지
- 이상하면 0.5 로 되돌림

### ☐ 1-2. 조향 보정값 벤치 측정 (차를 들고)

- 차를 띄우고 조향 ±0.1, ±0.2, ±0.3 rad 를 명령해 **바퀴 실제 각도**를 잰다
  (각도기, 또는 바퀴에 자를 대고 사진)
- 로그 추정: 실제 ≈ 명령 × 0.89
- 맞으면 → `vehicle_car1.yaml` 의 `vesc.steering_angle_to_servo_gain` 을 **÷0.89** (약 12% 크게)
  - 이러면 `apply_vehicle.py` 가 계산하는 명목 `max_steer` 도 실제(약 0.43 rad)에 가까워진다
  - 바꾼 뒤 `./race.sh steer-meas --car car1` 로 `steer_eff_max` 를 다시 재서 갱신
- 안 맞으면 → 부족분은 링크·서보세이버가 하중에 휘는 것. 기구 점검 대상

### ☐ 1-3. 새 mintime 라인으로 다시 달리기

- 분석한 로그는 전부 **옛 라인**(`c11_clean_wp_kappa_pre`, 27.5° 가정)이라
  급한 코너(κ>1)의 29% 가 조향 끝까지 꺾여 있었다 — 라인이 차가 못 도는 곡률을 요구한 탓
- 새 라인: `c11_clean_wp_mintime` (실측 21.2° 기준)
- 1-1 / 1-2 와 **같은 날 섞지 말 것** — 라인을 바꾼 효과와 상수를 바꾼 효과가 구분 안 됨

### ☐ 1-4. (마지막) `l1_min` 1.2 → 1.0 시도

- 바깥 치우침은 L1² 에 비례 → 줄이면 덜 밀림
- 하지만 루프 지연(실측 0.18 s)에 대한 여유가 줄어 흔들릴 수 있다
- **1-1, 1-2 로 원인을 먼저 고친 뒤에만** 시도. 흔들리면 1.1 → 원복

### ☐ 1-5. 고속 데이터 확보

- 지금 로그는 전부 q2(grip 0.5), 최고 3.2 ㎧ — **그 이상 속도에서의 언더스티어는 모른다**
- q1/q3 로 더 빠르게 달린 로그가 쌓이면 다시 분석

### ☐ 1-6. (선택) `./race.sh ctrl-meas` 도구 만들기

- `steer-meas` 처럼 로그를 넣으면 아래 2절 표들과 권장 `slip_gain`, 정적 조향비를 출력
- 상수를 바꿀 때마다 전/후를 같은 방법으로 비교할 수 있게

## 2. 분석 결과 (근거)

### 2-1. 곡률 구간별 추종

| 라인 곡률 | 평균 속도 | 바깥 치우침 | 오차 p95 | 조향 포화 |
|---|---|---|---|---|
| 직선 (κ < 0.15) | 2.2 ㎧ | 0.07 m | 0.42 m | 0% |
| 완만 (0.15~0.5) | 2.0 | 0.08 m | 0.39 m | 2% |
| 중간 (0.5~1.0) | 1.6 | **0.17 m** | 0.47 m | 4% |
| 급함 (κ > 1.0) | 1.4 | 0.13 m | 0.36 m | 29% |

- 전체 평균 오차 0.16 m, p95 0.41 m
- 명령 조향이 실측 한계(0.37 rad)를 넘은 비율: 23%

### 2-2. 실제 곡률 / 명령 조향 곡률 (지연 0.18 s 보정)

| 속도 [㎧] | 0.8~1.4 | 1.4~1.8 | 1.8~2.2 | 2.2~2.6 | 2.6~3.4 |
|---|---|---|---|---|---|
| 비율 | 0.85 | 0.84 | 0.77 | 0.69 | 0.70 |

- 조향 크기와는 무관(0.80~0.82), 좌우 차이 없음(0.807 / 0.810)
- `1/비율 = 1.13 + 0.034·v²` 로 나눠 보면:
  - 속도 0 에서의 비율 **0.89** → 정적 조향비 (1-2)
  - v² 항 → 언더스티어 0.012 rad/(㎧²) = 횡가속 1 ㎧² 당 0.7° (1-1)
- 지연은 0.15~0.20 s 에서 잔차가 가장 작음

### 2-3. 계산이 실측과 맞는지

일반 코너(δ 0.3 rad, 횡가속 1.5 ㎧²)에서 모자란 조향:

```
정적 부족     0.30 × (1/0.89 − 1)          = 0.038 rad
언더스티어    1.5 × (0.0136 − 0.0071)       = 0.010 rad
합계                                        = 0.048 rad (2.7°)
→ 순수추종 정상편차  0.048 × L1² / (2·L) = 0.048 × 1.44 / 0.66 = 0.10 m 바깥
```

실측 0.08~0.17 m 와 맞다.
